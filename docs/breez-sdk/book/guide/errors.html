Breez SDK

Handling errors

When a BreezSdk method fails, it returns an SdkError (SdkException in Kotlin and C#). Each kind of failure is its own variant, so you can match the ones your app handles and fall back to the error's message for the rest. Some variants carry fields with the detail you need to recover, such as the fee a deposit claim requires. Some variants also carry a docs_urldocs_urldocsUrldocsUrldocsUrldocsUrldocsUrlDocsUrlDocsUrl field linking to their section below.

Catching errors

Rust
match sdk.prepare_send_payment(request).await {
    Ok(prepare_response) => {
        info!("Payment prepared: {:?}", prepare_response.payment_method);
    }
    Err(SdkError::InsufficientFunds { .. }) => {
        info!("Not enough funds for this payment");
    }
    Err(SdkError::CrossChainDisabled { docs_url }) => {
        info!("Cross-chain payments are not enabled, see {docs_url}");
    }
    Err(error) => {
        info!("Failed to prepare the payment: {error}");
    }
}

How errors appear differs by language:

  • JavaScript (WASM): errors are thrown as standard Error objects, typed as SdkError. The message describes the error, and errors that link to the guide also have a docsUrl property. There are no per-variant error types to match on.
  • React Native: each variant is a class under SdkError. Match it with instanceOf and read its fields from inner.
  • Other languages: each variant is its own error type or case, with its fields available directly.

Deposits the SDK claims in the background don't throw. When one of those claims fails, the reason is recorded on the deposit's claim_errorclaim_errorclaimErrorclaimErrorclaimErrorclaimErrorclaimErrorClaimErrorClaimError instead. It uses the same MaxDepositClaimFeeExceeded, MissingUtxo and DepositTooSmall cases described below, and any other failure is recorded as a generic message. See Handling the outcome.

Error reference

SparkError

An operation on the Spark network failed, such as a transfer or a call to the Spark operators. The message carries the underlying cause.

InsufficientFunds

The balance can't cover the payment and its fees. token_identifiertoken_identifiertokenIdentifiertokenIdentifiertokenIdentifiertokenIdentifiertokenIdentifierTokenIdentifierTokenIdentifier is set when there are insufficient funds to make a token payment. You can check balances with get_infoget_infogetInfogetInfogetInfogetInfogetInfoGetInfoGetInfo.

InvalidUuid

An identifier passed to the SDK is not a valid UUID.

InvalidInput

The request was rejected as invalid: a malformed address or invoice, a missing or out-of-range value, an option that doesn't apply to the request, or a lookup for something that doesn't exist. The message names the problem. Fix the request rather than retrying it unchanged.

NetworkError

A request to a remote service failed, for example an LNURL server, the Lightning address service, a fiat rate provider or a USDC/USDT provider. The message carries the service's response.

StorageError

Reading or writing the SDK's local storage failed.

MaxDepositClaimFeeExceeded

Claiming a deposit costs more than the maximum fee allows, or no maximum fee is set. required_fee_satsrequired_fee_satsrequiredFeeSatsrequiredFeeSatsrequiredFeeSatsrequiredFeeSatsrequiredFeeSatsRequiredFeeSatsRequiredFeeSats gives the fee the claim needs, so you can ask the user to approve it and claim again with a higher maximum. See Handling the outcome.

MissingUtxo

The deposit transaction has no output at the given index, so the transaction id or output index doesn't match a real deposit.

DepositTooSmall

After the claim fee, the deposit would credit less than the dust limit. No maximum fee makes it claimable, but a drop in on-chain fees can. See Handling the outcome.

DepositClaimInProgress

Another claim on this deposit is already running, or an early claim was already made. It is not a failure to show the user, and it needs nothing from you. See Claiming a deposit manually.

LnurlError

The LNURL service returned an error while paying or withdrawing. The message carries the service's reason. See LNURL-Pay and LNURL-Withdraw.

Signer

The signer failed, for example while signing or deriving a key. With an external signer, the message carries the error your signer returned. See Using an External Signer.
