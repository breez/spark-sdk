# Using x402

[x402](https://github.com/x402-foundation/x402) is a protocol for paying for HTTP resources and MCP tools. A server answers an unpaid request with a payment challenge, and the client pays it and sends the request again with proof of payment. The Breez SDK supports x402 over Lightning (the `exact` scheme on Bitcoin Lightning), for both HTTP requests and MCP tool calls:

- **[Paying with x402]** - Pay for HTTP resources and MCP tools that ask for an x402 payment
- **[Charging with x402]** - Charge for your own HTTP resources and MCP tools

## Working with other x402 implementations

The SDK follows the x402 specification on both sides: it pays challenges from other servers that follow it, and other clients that follow it can pay its challenges. It differs in three ways:

- The scheme expects each receiver to have a Lightning key of its own, while every Spark invoice is signed by the same service provider key. The SDK follows the [proposed option for a shared key](https://github.com/x402-foundation/x402/pull/3699): each challenge carries a quote only the issuing SDK can check, and settling a payment also confirms with Spark that it was received. Clients send the quote back without needing to read it.
- On regtest and signet, challenges use network identifiers the specification doesn't define yet.
- Prices are in sats, since Spark invoices are for whole sats.
