# End-User Fees

**The Breez SDK is free for developers.** 

There are small fees for end-users to send and receive payments.

You can learn more about end-user fees [here](https://docs.spark.money/wallets/estimate-fees).

## Earning fees

You can add your own fee to your users' payments, set in the [Partner portal](https://partners.breez.technology/):

- [Earning fees on Lightning payments](./lightning_partner_fees.md)
- [Earning fees on USDC/USDT payments](./cross_chain_partner_fees.md)
